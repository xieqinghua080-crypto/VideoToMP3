# 视频转 MP3 (VideoToMP3) — 支持

将视频中的音轨提取并转换为 MP3，可导出到 U 盘、iCloud 或系统「文件」App。

## 常见问题

**Q: 转换后的文件存在哪里？**
A: 保存在 App 内的「媒体库」页面，也可随时导出到外接 U 盘或 iCloud Drive。

**Q: 会上传我的视频吗？**
A: 不会。所有提取与转码都在你的 iPhone 本地完成，App 不联网、不收集任何数据。

**Q: 支持哪些视频格式？**
A: 相册和「文件」App 中 iOS 能播放的视频均可，包括 MOV、MP4、M4V 等。

**Q: 支持哪些输出格式？**
A: MP3（128 / 192 / 320 kbps）与 M4A。
